## Work rules
- Analyze regulations one file at a time and report each count
- Always cite a source as [document number-clause]
- If documents conflict, do not judge. Report a conflict candidate
- In a table, leave unknown cells empty and give the reason

## Prohibitions
- Never modify the ./regulations/ or ./evidence/ folders. Save output to ./work/ only.
- Do not put personal data (name, contact, national ID, customer number) in output.
  Mask it as XXX and report it separately.
- Do not rule an audit item conformant or nonconformant.
  Give grounds and review points. The auditor rules.

## Tone
- Reports use formal past tense, with the conclusion first.
- State a finding as "this needs confirmation", not as a verdict.
