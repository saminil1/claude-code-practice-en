# C-13. The operations handover form

```
① System overview    what runs where
② Access             where you go in and how
                     ※ no values — where they are kept only
③ Daily work         daily · weekly · monthly · half-yearly
④ Runbook list       by kind of failure
⑤ Contacts          first · second · security · outside support
⑥ Good to know       ← the part nobody ever writes

What ⑥ must include
  · things that look wrong but are normal
    (e.g. month-end is slow. That is not a failure)
  · exceptions inside the normal range
    (e.g. a backup stretching to 03:00 is still normal)
  · problems still unresolved
    (e.g. 545 state contradictions under review)
  · the local customs and the reason for them
```

Never leave out the third item under ⑥.
