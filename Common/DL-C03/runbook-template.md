# C-2. The standard runbook layout

```
## Runbook [number] [name of the failure]

  Symptom   — what you see that tells you it is this
  Impact    — what stops working
  Look now  — what to check inside 3 minutes (in order)
  Actions   — step by step (safest first)
  ⚠ Do not — what a panicking person reaches for
  Contacts  — first / second / approver
  Record    — time · state · cause · action · recovery

  ※ Read it through once every half-year and check it is current
```
