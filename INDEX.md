# Reader Resource Packs — Claude Code for Non-Developers (English)

32 packs. Every prompt, checklist, and table printed in the two volumes.

## Two names, one pack

The book names each pack twice — for example
"the Volume 1 Chapter 1 pack (**v1_01_pack.zip**, **DL-1-01**)".
The file you download carries the second name only:

    the book says          the file is called
    v1_01_pack.zip    →    DL-1-01.zip
    v2_05_pack.zip    →    DL-2-05.zip

The `v*_pack.zip` form is the older naming and no file uses it any more.
Go by the **DL** code and you will always land on the right pack.

## What is in every pack

    README.md       what the pack holds and how to use the prompts
    prompts.md      every prompt printed in that chapter, in full
    checklist.md    the chapter checklist
    tables.md       the tables from that chapter
    MANIFEST.txt    file list with sizes and hashes

Do not run the exercises on original work files, and do not use files that hold
personal data or company secrets. Work with a copy.
