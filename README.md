# Claude Code for Non-Developers — Practice Files

Practice material for *Claude Code for Non-Developers*, Volumes 1 and 2
(Choongon (Mark) Lee · ISC Publishing).

    Volume 1 — Foundations    Automate real office work with AI, no code
    Volume 2 — In Practice    Context, harness, loops, and ISO audit automation

---

## Getting it — match the volume you bought

Whether you bought one volume or both, **one download is enough.** The material the two
volumes share is included in each bundle.

| You bought | Take | Size |
|---|---|---|
| **Volume 1 — Foundations** | `zips/Vol1-complete.zip` | 169 KB |
| **Volume 2 — In Practice** | `zips/Vol2-complete.zip` | 95 KB |
| **Both** | the green **Code ▾ → Download ZIP** at the top right | 1.3 MB |
| **A single chapter** | one pack, such as `zips/DL-2-01.zip` | a few KB |

In `zips/`, click the file name, then the **Download** button on the right.

The book says DL-2-01 → `zips/DL-2-01.zip`

With git:

```bash
git clone https://github.com/saminil1/claude-code-practice-en.git
```

The unpacked files are here too, so you can look inside before you download.

## Folders

Laid out the way the book is — volume first, then chapter.

```
Vol1/      packs for Volume 1 chapters      DL-1-04 … DL-1-14
Vol2/      packs for Volume 2 chapters      DL-2-01 … DL-2-13
Common/    shared across both volumes       DL-C02 · DL-C03
zips/      one zip per pack                 when you want a single chapter
```

| Folder | Packs | What is in it |
|---|---|---|
| `Vol1/` | 11 | 28 office files, a mailbox, a schedule, spreadsheet registers, contract and proposal PDFs, a staff list |
| `Vol2/` | 12 | the twelve in-house regulations, ISMS evidence, outsourcing contracts, Odoo migration data, cloud configuration and logs |
| `Common/` | 2 | `DL-C02` the CLAUDE.md and settings skeletons and the four harness tests · `DL-C03` forms: agent design canvas, runbook, change management, handover |

⚠ **Volume 1 Chapters 1–3 and `DL-C01` · `DL-C04` have no folder here.** Those packs hold
only what came out of the book itself — prompts, tables, a glossary. See below.

## What is here, and what is not

    Here          practice data — templates, configuration, regulation samples
    Not here      the prompts, tables, checklists, and glossary from the book

The second group is **book content**. The colophon reserves the reader resource pack for
the person who bought the book, so it is not published here.

**The complete pack for every chapter, book content included, is in the isccert.org book
library.** The QR code on each chapter opener takes you there.

---

## Before you start

⚠ **Do not run the exercises on original work files**, and do not use files that hold
personal data or company secrets.

Everything here is synthetic. The company names, people, contact details, and amounts are
invented and match no real ones. Put an approval step in front of anything you cannot undo
— deleting, sending, overwriting. Volume 1 Chapter 14 covers how to judge this.
